The problem

On-chain stocks never close. Their price anchor does.

Reference reprices. If the rumor was wrong, the agent bought 10% above fair value.

The insight

Spend caps and allowlists don’t know what time it is.

Today’s agent guardrails ask

  • Is this token allowed?
  • Is it under the daily budget?
  • Is the agent still authorised?

Gap Guard also asks

  • Is the real market open right now?
  • How far is this price from the reference?
  • Is that gap acceptable for this hour?
The solution · GapGuardVault.sol

Four checks, enforced on-chain before every trade.

01

Stock allowlist

Only bStocks / Ondo / xStocks you picked. A prompt-injected “buy RUG” reverts.

02

Daily budget

e.g. 100 USDT per day, no matter how convinced the model is.

03

Market-aware gap band

DEX price vs reference: max 5% while NYSE is open, 3% while it’s closed.

04

Kill switch

Owner freezes the agent in one tx. Every trade is a public event.

gap = |dexPrice − referencePrice| / referencePrice  →  if gap > band(marketOpen) → revert PriceGapTooWide
